## How to Take Screenshots

### For UI Screenshots:
1. Run the application: `npm run dev` from root directory
2. Navigate to each page
3. Take full-page screenshots
4. Save with the naming convention above

### For API Testing Screenshots:
1. Use Postman, Thunder Client, or Insomnia
2. Test each endpoint
3. Show the request (method, URL, headers, body)
4. Show the response (status code, body)
5. Save with the naming convention above

## Tips for Good Screenshots:
- Use full window screenshots
- Ensure text is readable
- Show relevant data (not empty states)
- Include browser/tool UI for context
- Highlight important features if needed
- Use consistent window size for UI screenshots
